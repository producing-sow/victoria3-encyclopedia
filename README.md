# 维多利亚 3 百科 · Victoria 3 Encyclopedia

最新发布：[v2026.11.15 · 下载与更新说明](https://github.com/producing-sow/victoria3-encyclopedia/releases/tag/v2026.11.15) · [完整更新记录](CHANGELOG.md)

**简体中文** | [English](README.en.md)

一款基于《Victoria 3》游戏文件构建的交互式百科，将建筑生产、资源地图、公司、文化宗教、地缘政治、法律、人物和军队资料汇集在一起。支持中英文切换、离线浏览、组合筛选与可视化统计，让查阅规则、比较方案和规划开局更直观。

从一座工厂的投入产出，到一个国家的人口构成；从法律与修正案的效果，到人物的意识形态与性格特质——通过相互关联的条目、地图和图表，探索工业时代的经济与社会。

## 主要功能

| 模块 | 可以查看和比较什么 |
| --- | --- |
| 建筑与生产 | 切换原版／工业之链 MOD，自由组合各版本的生产方式，查看投入、产出、用工与理论净产值；浏览产值排行、商品基础价格及解锁条件。 |
| 全州资源地图 | 在交互地图上查看资源、耕地、人口、文化分布与州特质；组合筛选资源需求，定位目标州。 |
| 公司百科 | 查询主营和扩展行业、总部偏好、声望商品、繁荣加成及成立条件，并按行业与效果筛选。 |
| 文化与宗教 | 查看文化传承、语言、传统、信仰与开局人口分布；使用法律比较器分析不同文化和宗教人群的接纳分。 |
| 地缘政治 | 查看 1836 年国家档案、人口构成饼图、资源、建筑、军队、开局法律、国家集团与多层附属关系。 |
| 法律百科 | 按游戏分类展示法律与特殊制度，查看修正案、税负和机构等级的影响；以国家名单和饼图统计开局采用情况。 |
| 人物百科 | 按国家、姓名、角色、意识形态及特质筛选历史人物记录；查看人物档案、法律立场与不同身份下生效的特质效果。 |
| 军队百科 | 查询陆军兵种、海军舰种、动员选项与补给效果；查看各国开局编制、军力构成和全球分布。 |
| 版本记录与对比 | 保存本地数据快照，比较字段变化，并对比不同快照中的生产方式、资源与人口数据。 |

## 使用体验

- **中文 / English**：通过页面顶部的语言选项切换，并保留语言偏好。
- **图标与地图**：使用游戏图标、中文及英文名称辅助识别；关联条目之间可直接跳转。
- **组合筛选**：将国家、类别、名称、资源、意识形态等条件结合起来，快速缩小查询范围。
- **图表与导出**：通过饼图、明细表及 CSV / JSON 导出查看和整理数据，具体功能以各页面为准。
- **离线与响应式布局**：生成后的百科可直接在浏览器中打开，适配桌面与窄屏设备，无需后台服务。
- **可核对的数据来源**：相关条目提供原始定义、条件、来源或统计口径，区分显式设置、默认推定和条件内容。

## 快速开始

1. 下载或克隆项目，保留完整目录结构，包括 `assets/`、`en/` 以及各数据文件。
2. 使用浏览器打开 `index.html`，即可浏览已生成的百科。
3. 在页面顶部切换语言，通过侧栏进入其他模块。

直接打开 HTML 不需要 Python，也不会读取本机游戏安装目录。Windows 用户还可运行 `打开百科.cmd`；该入口会先尝试检查本机游戏数据变化，再打开页面。

更详细的操作和计算说明见 [使用说明](使用说明.md)。

## 数据更新与项目结构

前端使用 HTML、CSS 和 JavaScript；Python 脚本从本地游戏安装目录提取定义、本地化文本和图像，生成浏览器可读取的数据。重新提取需要本地游戏文件、Python、Pillow 和 NumPy；部分英文补全流程可能访问网络。

Windows 下可使用 `更新数据.cmd` 强制更新，或运行 `python version_history.py --force`。目前构建脚本采用作者本机的默认游戏路径；在其他电脑上重新生成前，需要核对并调整脚本中的安装目录。更新流程仅读取游戏文件，不修改游戏安装内容。

| 文件或目录 | 用途 |
| --- | --- |
| `index.html`、其他 `*.html` | 百科各模块入口 |
| `*.js`、`*.css` | 页面交互、数据与样式 |
| `assets/`、`en/` | 图片素材与英文数据 |
| `build_*.py` | 游戏数据提取与本地化生成 |
| `version_history.py`、`history/` | 数据更新、快照与版本记录 |
| `verify-*.cjs`、`verify-*.py` | 各模块的数据和逻辑校验 |

## 数据口径

当前内容基于本地提取的 **Victoria 3 1.15.0（Ivan-Chai）** 数据；具体版本以页面标注和快照记录为准。

- 开局统计以 1836 年静态定义为基础，不代表当前存档。部分运行时脚本、事件和条件不会被执行；页面会注明默认推定或条件记录。
- 建筑理论净产值按基础商品价格计算，不扣工资、税费等，不等于实际利润，也不代表市场中的最优生产方案。
- 法律、机构和修正案的效果预览用于比较定义，不模拟所有实际颁布条件或存档修正。
- 人物统计以固定模板与创建记录为单位，同一历史人物可能存在不同模板；未收录无固定名字的随机生成器。
- 版本对比仅覆盖已经保存的原版快照。01 建筑与生产单独提供工业之链 MOD 数据集，不与原版快照混合。

## 更多公司 MOD 图鉴

03 公司百科提供“原版公司”和“更多公司 MOD”两个独立页签。MOD 本体来自创意工坊 `3032185644`，汉化来自 `3086429193`；当前提取 923 家公司，其中 692 家新增、231 家覆盖原版定义。可按新增/覆盖、地区、行业与名贵商品筛选，查看成立条件、繁荣加成和图标，或单独导出 CSV。覆盖条目可跳转核对原版定义；覆盖不一定代表内容发生变化。

双击 `更新更多公司图鉴.cmd` 可重新读取已安装的本体与汉化包。默认读取本机 F 盘 Steam 目录；其他安装位置可向 `build_mod_companies.py` 传入 `--game-root`、`--mod-root`、`--translation-root`。提取结果独立保存为 `mod-companies-data.js` 与 `en/mod-companies-data.js`，不修改游戏、创意工坊文件或原版快照。源文件中的异常加成会在详情提示，并保留原始定义供核对。

### 一键更新与原版快照

双击 `打开百科.cmd` 或 `更新数据.cmd` 启动本地服务，在侧栏点击“更新百科”，输入 **Victoria 3 根目录**（包含 `game` 与 `launcher`），点击“更新整个百科”。服务窗口在更新期间需保持打开。需要 Python 3.10+、Pillow、NumPy；缺少依赖时运行 `python -m pip install Pillow numpy`。

更新会重新生成八个原版模块、图标和中英文内容。按原版文件内容而非时间戳判断差异；有变化才新增快照，相同版本号的热修复也能记录。完成后从“版本档案与对比”选择两份快照。旧快照保留；生成失败不替换当前百科。路径只保存在本机，不提交至 GitHub。

原版更新不加载创意工坊或用户 MOD，已有 MOD 图鉴继续独立维护。直接改动游戏安装目录仍算内容差异；要保证纯原版，请用 Steam 验证文件完整性。静态网页或 GitHub 页面不能直接读取本机游戏并运行提取，请通过上述本地启动器更新。

命令行亦可使用：`python version_history.py --root "D:\SteamLibrary\steamapps\common\Victoria 3" --force`。`--force` 表示完整重建，不会强制产生重复快照。


### 从百科启动更新与 MOD 路径

首次运行 `更新数据.cmd` 或 `打开百科.cmd` 会为当前 Windows 用户注册 `v3encyclopedia://update` 启动入口。之后直接在百科的“更新百科”页面点击“启动本地更新”，按浏览器提示打开本地程序即可；服务已运行时可直接在页面提交更新。移动文件夹后重新运行 CMD 注册新位置。注册不需要管理员权限；可删除注册表 `HKEY_CURRENT_USER\Software\Classes\v3encyclopedia` 解除关联。

更新范围可选“仅原版”“仅所选 MOD”或“原版和所选 MOD”。自动查找当前游戏所在 Steam 库的创意工坊目录；MOD 位于其他库或手动安装时填写实际路径。支持工业之链（3723966801）、真实资源（3459869359）、更多公司（3032185644），更多公司同时需要汉化目录（3086429193）。只更新勾选的项目，路径保存在本机。

MOD 只替换当前中英文数据，**不生成快照，也不改动原版快照**。MOD 更新失败时保留此前 MOD 数据。“一起更新”分两步保存；若原版已成功而 MOD 失败，已完成的原版更新仍保留。单独更新 MOD 前，原版百科版本需与游戏版本一致；不一致时选择一起更新。
