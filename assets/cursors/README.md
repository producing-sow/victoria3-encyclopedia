# Victoria 3 mouse cursors

Copied unchanged from the local Victoria 3 installation:

- `game/gfx/cursors/standard.cur` and `standard.png`: default arrow.
- `game/gfx/cursors/hover_tooltip.cur` and `hover_tooltip.png`: highlighted arrow for interactive elements.

All images are 32 × 32 pixels; CUR hotspots are (0, 0). Native CUR files are preferred, with PNG and system cursor fallbacks. Game artwork belongs to its respective rights holders.
