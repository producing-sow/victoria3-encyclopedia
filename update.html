从本机游戏更新

更新全部原版模块、游戏图标和中英文内容。只读取游戏文件，不修改游戏安装。

选择内含 game 和 launcher 的 Victoria 3 文件夹。Steam → 游戏属性 → 已安装文件 → 浏览，可查看目录。

MOD 安装位置

勾选需要更新的 MOD。自动查找当前游戏所在 Steam 库；其他库或手动安装的位置可自行填写。更多公司还需要独立汉化目录。路径会保存在本机。

MOD 只覆盖当前中英文数据，不生成快照。原版与 MOD 分别保存；若 MOD 更新失败，已成功完成的原版更新仍保留。

启动本地更新 ↗

首次请双击百科文件夹中的「更新数据.cmd」，注册本地启动入口。以后可以在百科内点击“启动本地更新”，按浏览器提示打开程序。若移动了百科文件夹，请重新运行一次 CMD。需要 Python 3.10+、Pillow 和 NumPy。

快照规则
按原版文件内容校验差异，版本号相同的热修复也会记录。重复更新、文件时间变化不会产生重复快照；首次采集会建立可追溯的原版快照。已有历史快照保留，可在版本档案选择两份进行对比。
原版快照不包含 MOD；可在上方选择单独更新 MOD 或一起更新。若直接修改了游戏安装文件，这些修改仍会被识别为内容差异；需先通过 Steam 验证文件完整性以恢复原版。未成功生成的数据不会替换现有数据。
